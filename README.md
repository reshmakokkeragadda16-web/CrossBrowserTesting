# Cross-Browser Testing Using Selenium and Python

## Project Overview
This DevOps project automates login testing in Google Chrome
and Mozilla Firefox using Selenium WebDriver and Python.

## Technologies Used
- Python
- Selenium WebDriver
- Google Chrome
- Mozilla Firefox
- HTML and CSS
- Python unittest

## Test Cases
1. Valid login credentials
2. Invalid login credentials
3. Valid login in Chrome
4. Invalid login in Chrome
5. Valid login in Firefox
6. Invalid login in Firefox

## How to Run
1. Install the dependencies:
   pip install -r requirements.txt

2. Start the local web server:
   python -m http.server 8000

3. Open another terminal and run:
   python -m unittest -v test_cross_browser.py

## Expected Result
All four automated test executions should pass.

## Conclusion
The project demonstrates automated cross-browser login
testing using Selenium WebDriver and Python.
